# unzip-allinone

一个本地运行的批量解压 Web 工具。它会扫描指定目录中的 ZIP、7z 和分卷压缩包，并通过浏览器界面统一执行解压任务。

## 功能

- 按目录和深度扫描压缩包
- 支持 ZIP、7z、`.7z.001` 和纯数字分卷
- 支持统一密码、建议密码和常见密码黑话转换
- 实时显示任务与单个压缩包的解压进度
- 支持跳过、覆盖或重命名冲突文件
- 可选择在解压成功后删除原压缩包

## 环境要求

- Go 1.22 或更高版本
- `7za` 或 `7z` 命令可在 `PATH` 中使用

Debian/Ubuntu 可安装：

```bash
sudo apt install p7zip-full
```

## 运行

```bash
go run .
```

启动后访问 <http://127.0.0.1:42547>。

也可以先构建再运行：

```bash
go build -o unzip-allinone .
./unzip-allinone
```

## 测试

```bash
go test ./...
```

## 使用提醒

服务默认监听 `0.0.0.0:42547`，同一网络中的其他设备可能访问。请仅在可信网络中运行，并在删除原压缩包前确认扫描和解压结果。
